# OSSÁRIO

Dungeon crawler em primeira pessoa no navegador. Explore a cripta do rei morto, lute por turnos, saqueie os ossos e desça até o trono.

Feito com Grok Build.

## Como jogar

- **Andar:** W / setas, ou o pad na tela
- **Virar:** A / D
- **Agir:** E / Espaço — baús, portas, escadas, inimigo à frente
- **Inventário:** I
- **Combate:** Atacar, Defender, habilidade, poção (e frasco, se tiver)

O progresso fica no aparelho. A morte apaga a expedição.

## Rodar local

```bash
npm install
npm run dev
```

Abre em `http://localhost:8080`.

## Stack

React 19, TanStack Start, Tailwind v4, Zustand, raycaster 2D no canvas.
